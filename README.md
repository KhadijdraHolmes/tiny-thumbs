I. Project Description

The Tiny Thumbs – Toddler Sitter Rating App is a mobile Android application created to help toddlers and parents give feedback about babysitters in a simple and easy way. The app allows toddlers to choose an emoji that best describes how they felt about their sitter, while parents can write a short review. The main goal of this project was to design an app that is easy to use, visually clear, and appropriate for very young users, while also demonstrating basic Android app development skills.

II. Problem Addressed

Toddlers are not able to write or explain their experiences clearly, which makes it difficult for parents to understand how their child felt about a babysitter. Many existing rating or review apps are designed for adults and are too complicated for young children to use. This app addresses that problem by giving toddlers a way to express feedback using emojis, while parents can provide additional details through a written review.

III. Platform

This application was developed for the Android platform using MIT App Inventor. MIT App Inventor was chosen because it allows beginners to build functional apps using a visual, block-based programming approach. The platform makes it easier to focus on app logic and user interaction without needing advanced coding experience. The project is shared as an .aia file for review and grading purposes.

IV. Front-End and Back-End Support
Front-End

The front-end of the app was designed with simplicity in mind. Large buttons, clear text, and emoji icons were used so that toddlers can interact with the app easily. The app uses two screens:

Screen1 (Home Screen): Displays the app title and a button to begin rating a sitter.

RatingScreen: Allows the toddler to select an emoji rating and lets parents enter and submit a written review.

Back-End

The back-end logic is handled using MIT App Inventor blocks. Button click events control navigation between screens, emoji selection updates feedback text, and text input blocks manage the parent review submission. Screen navigation is handled using proper open and close screen logic to keep the app flow simple and stable.

V. Functionality

The app includes the following functionality:

The app opens on a home screen with clear navigation.

Users can move to the rating screen to select an emoji rating.

The selected emoji displays feedback text on the screen.

Parents can type and submit a review.

The submitted review is displayed, and the input box is cleared.

A return home button allows users to go back to the main screen.

All features work as intended and meet the functional requirements of the assignment.

VI. Design (Wireframes)

Before building the app, simple wireframes were used to plan the layout and screen flow. These wireframes helped decide where buttons, labels, and text boxes should be placed. The focus was on keeping the layout clean and easy to understand, especially for young users. The final design closely follows the original wireframe plan.
